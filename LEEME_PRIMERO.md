# Primeros pasos

1. En Windows, haz doble clic en `ABRIR_DASHBOARD.bat`.
2. La primera vez se instalarán las dependencias; puede tardar unos minutos.
3. Se abrirá el dashboard en `http://127.0.0.1:8050/`.
4. Explora el histórico incluido o entra en **Previsión** para simular un
   proyecto por MW y MWh, o por volumen de balsa y salto neto.

Para actualizar los datos, copia `.env.example` como `.env`, añade tu token de
e·sios y ejecuta `ACTUALIZAR_DATOS.bat`. Lee `README.md` para el detalle y
`VALIDATION_REPORT.md` antes de utilizar una cifra en una decisión.
